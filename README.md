# Lighthouse — цепная реакция

Играбельный браузерный прототип круговой обороны Маяка из **While the Lighthouse Shines**. Существа идут волнами с разных сторон; световой импульс уничтожает цель, после чего свет распространяется цепной реакцией между соседними существами.

> **Происхождение:** автономная реализация механик версии 2 для GitHub Pages. Исходный архив прототипа, созданного в Sites, недоступен для прямого экспорта в текущем окружении, поэтому этот репозиторий не является точной копией исходного проекта Sites.

## Запуск
Открой `index.html` в браузере. Никакого сервера, сборки, внешних библиотек или API не требуется.

## Публикация GitHub Pages
Один раз выбери в репозитории **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**. После этого GitHub автоматически публикует файлы из корня `main` и пересобирает сайт при каждом обновлении этой ветки.

Ожидаемый адрес после включения: `https://alekseypilishkov-gif.github.io/lighthouse-chain-night/`. Если сайт не открывается, проверь настройки Pages и статус сборки в разделе **Actions**.

## Игровой цикл
- 5 волн с разных направлений, здоровье Маяка, три типа существ: обычные, бегуны и проводники.
- Один импульс запускает цепь вспышек. Важны плотность группы, расстояния и момент удара.
- После первой волны выбирается один из трёх модулей. После третьей выбранный модуль усиливается.
- Испытательная акватория с повторяемой расстановкой врагов и изменяемыми параметрами, сравнение модулей и текстовый отчёт.

## Модули пушки
- **Дополнительный накопитель**: 2 заряда (уровень I), 3 заряда (уровень II).
- **Отложенная вспышка**: помечает движущуюся цель, взрыв спустя 1,6 секунды (I), две метки, ручной подрыв и 3,6 секунды (II).
- **Переход через разрыв**: цепь может преодолеть один разрыв (I), два разрыва (II).

## Управление
| Действие | Управление |
|---|---|
| Прицел / выстрел | Мышь / левая кнопка |
| Выстрел по курсору | Пробел |
| Поставить метку | ПКМ (если модуль открыт) |
| Переключить режим | Q |
| Ручной подрыв | E (отложенная вспышка II) |
| Пауза | P / Esc |
| Заново | R |

Игра адаптирована под сенсорный ввод: для меток доступно переключение режима отдельной кнопкой.

## О проекте
Это **тест механики**, а не готовый боевой сегмент основной игры. Параметры волн и баланс улучшений предварительные. Содержимое не включает нарративные и графические ассеты основной игры.

Лицензию на повторное использование кода можно выбрать отдельно. Все файлы прототипа хранятся в корне репозитория.
